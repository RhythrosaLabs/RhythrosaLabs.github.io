# Dan Sheils

Creative technologist and multidisciplinary artist working across music, sound design, visual art, games, and software.

## Creative practice

- **Dan Sheils** is the personal identity for the work collected here.
- **[Noodlebake Records](https://noodlebakerecords.bandcamp.com/)** is the independent record label and creative imprint Dan founded.
- **[Creative Tools by Noodlebake](https://noodlebakecreates.bandcamp.com/)** publishes sample packs and sound resources.
- **[Rhythrosa Labs](https://github.com/RhythrosaLabs)** is Dan's creative software practice.
- **[Scattercrate](https://scattercrate.com/)** is a separate art shop.

## Experience

Past work includes contract AR/XR sound design with Rock Paper Reality, teaching introductory game design and generative AI at The Westport Library, and live-event audio work for the Town of Greenwich. Dan's wider practice includes studio and live sound, music production, radio, podcasts, visual media, and interactive projects.

## This website

The portfolio is a static site built with HTML, CSS, and JavaScript. `index.html` contains the main copy and project links; `script.js` provides the interactions and animated text; `style.css` defines the existing visual presentation.
